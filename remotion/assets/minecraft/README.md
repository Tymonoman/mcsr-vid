`textures/` holds textures from the official Minecraft 1.16.1 client jar (Mojang), used under the Minecraft Usage Guidelines. They are written by `scripts/seed-icons/bake.py`: the jar's own `assets/minecraft/textures/<path>.png`, raw bytes, for every texture a baked seed-icon scene draws (tints and animation frames are applied by `remotion/SeedScene.tsx` at render time, not in the files). Only the textures the icon scenes in `scripts/seed-icons/scenes/` use are kept; a bake adds any new one it needs. The thumbnail itself draws the rendered PNGs in `remotion/assets/seed-icons/`, not these.
