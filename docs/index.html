What this is

An open-source pipeline that turns a finished MCSR Ranked match into a single video showing both players' points of view side by side, synchronised to the frame, with a live split timer and match statistics overlaid. Output is published to the YouTube channel MCSR Replayoffs.

How it works

  • Reads match data — players, splits, results — from the public MCSR Ranked API.
  • Downloads the relevant window of each player's Twitch VOD.
  • Aligns the two recordings by detecting the pre-match countdown in each.
  • Renders the overlay and composites the finished video.

Who it is for

This is a personal tool, run by one person, publishing to one channel. It is not a service, has no accounts, and is not offered for other people to sign in to. The source is public so the method is auditable and so other runners can see exactly how their footage is handled.

Not affiliated with MCSR Ranked

This project is an independent third party. It uses the public MCSR Ranked API but is not endorsed by, or associated with, MCSR Ranked or Mojang.
