Summary

This application is operated by one person and acts only on that person's own YouTube channel. It has no user accounts, no sign-in for anyone else, and no analytics or tracking of visitors. It does not sell, share, or transfer any data to third parties.

Google user data it accesses

The application requests these OAuth scopes, and uses them only as described:

  • youtube.upload — to upload finished videos to the operator's own channel.
  • youtube.force-ssl — to set the title, description, and thumbnail of those uploads, and to read comments on them.
  • youtube.readonly — to read the operator's own channel and video list, so the tool can tell which matches have already been published.
  • yt-analytics.readonly — to read view and click-through statistics for the operator's own videos, used to decide which thumbnail to keep.

All four apply solely to the account that grants them. The application never requests access to anyone else's Google account and cannot act on one.

Where that data goes

The OAuth refresh token is stored in a single file on the operator's own machine and is never transmitted anywhere except to Google's own token endpoint. Video and analytics data retrieved from the YouTube API stay on that machine. Nothing is sent to any server operated by this project, because there is no such server.

Other data the project handles

The pipeline also reads publicly available match data from the MCSR Ranked API and publicly available Twitch VODs. That is public information about a public competitive match; it is not Google user data and is not covered by the scopes above.

Limited Use

This application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and removal

Access can be revoked at any time from the operator's Google Account permissions page, which immediately and permanently ends the application's access. Deleting the stored token file has the same effect locally.

Runners appearing in videos

Videos feature publicly broadcast Twitch VODs of ranked matches. Both players are credited by name in every video description. If you appear in a video and want it removed, open an issue on the project's GitHub and it will be taken down.
